ABOUT THE METRICS

What each number actually means

Declared completion: 33 records whose recorded status meets an explicitly documented completed-state mapping, divided by 54 applicable declared contracts. This is not independently verified project completion. Unknown states must be excluded and disclosed, not counted as incomplete silently.

Evidence reference coverage: 29 present applicable evidence references divided by 40 explicitly required evidence references in the fictional example. File presence does not prove the evidence is valid.

Independently verified completion: NOT_ASSESSED because no tested verification rules or approved executions support an evaluation.

Trends: the chart uses eight invented snapshots. A real Observatory must first capture compatible, timestamped, user-controlled snapshots; never reconstruct history from present records.

Scope: the completed percentage is a bounded declaration-based measure. Incomplete scans, unsupported formats or invalid WORK.json must turn the value into PARTIAL/UNKNOWN, not a confident percentage.
